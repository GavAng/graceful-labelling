# graceful-labelling

## Requirements

```
- python >= 3.13
- ipykernel >= 6.29.5
- matplotlib >= 3.10.3
- networkx >= 3.5
```

### `ipykernel`

Required for Jupyter to work.

### `matplotlib`

Visualises the graphs.

### `networkx`

Stores the graphs and their logic. Unlike the other two packages, we actually need to import this one to use other parts of the codebase.

## Codebase

I have created an in-depth and interactive exploration of the codebase in `tutorial.ipynb`. As long as you have the above packages installed in your environment the jupyter notebook should run with no issues.
